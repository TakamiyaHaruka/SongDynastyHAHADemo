# 桌面无障碍检查

本项目按桌面使用场景维护：功能回归使用 Chromium、1280 / 1440px、明暗主题；无障碍扫描使用 1440px、明暗主题。当前工作不增加移动端适配或移动端检查矩阵。

## 自动检查

```sh
pnpm build
pnpm test:a11y
```

`e2e/accessibility.spec.ts` 使用本地开发依赖 `@axe-core/playwright`。按 [Playwright 官方无障碍测试说明](https://playwright.dev/docs/accessibility-testing)，检查 `wcag2a`、`wcag2aa`、`wcag21a`、`wcag21aa`，并增加 `best-practice` 标签。保留色彩对比度、表单名称、标题层级与地标规则，不使用排除节点或禁用规则来掩盖结果。

覆盖首页、文章总目、分类、标签、文章详情、友人、关于、RSS、404；另检查检索结果及空结果、原生展卷对话框、音乐加载失败和色谱复制后的状态。键盘用例验证 Tab 首先到达“跳转到正文”、Enter 后正文取得焦点，以及输入关键词后按 Enter 完成检索。

所有扫描结果以完整 JSON 附在 Playwright 报告中，包括 violations、incomplete 和通过项；自动判定要求 violations 为空。`incomplete` 仍需按报告中的节点人工判断。`pnpm test:e2e` 与 `pnpm validate` 均包含扫描，CI 检查通过后才继续部署，失败时上传报告、截图和 trace。

## 本轮修正

- 音乐选曲按钮使用自然文本名称，保留曲名、歌手和曲目信息；相邻封面作为重复装饰使用空 alt。原曲链接的 aria-label 包含完整可见文字“在 Apple Music 听原曲”。
- 色谱按钮使用自然文本名称；显示“已复制!”时，朗读名称随可见反馈一起更新。
- 正文跳转目标可接受程序焦点。御制艮岳记移除隐藏的重复标题，并把四个主章节改为 h2，保留章节文字与锚点。
- 浅色检索提示改用正文色，保证其在案头纸色背景上的对比度。

## 人工复核

自动扫描不能覆盖完整无障碍体验。改动交互后仍需复核键盘操作顺序、焦点可见性、展卷关闭后的焦点恢复、当前章节与结果播报，以及叠在画作上的文字在两种主题下的可读性。通过自动扫描不等同于完整 WCAG 合规认证。
