## 2026-10-22：画册大图浏览

实现范围：

- 13 幅画作均可通过原生按钮打开原生 `<dialog>`，以完整构图显示。
- 上一幅、下一幅和左右方向键循环浏览，显示画名与当前位置。
- 支持 Esc、关闭按钮及遮罩关闭；Tab / Shift+Tab 在对话框内循环。
- 打开时锁定页面滚动；关闭时恢复原滚动位置、行内样式和触发按钮焦点，保留画册展开状态。

- 大图只在打开和切换时设置地址；保留原有 SVG、首幅优先和其余画作懒加载。加载中及失败时提供状态提示。

- `npm run build`：12 个页面构建成功。
- `git -c core.safecrlf=false diff --check`：通过。

## 2026-10-22：音乐、发布规则与浏览器回归

实现范围：

- 音乐选曲与播放改为独立的原生按钮，消除交互控件嵌套；方向键 / Home / End 选曲，Enter / 空格操作按钮，Tab 在操作间移动。
- 增加加载、试听、暂停、结束、失败与无试听状态，通过 polite live region 提示；加载可取消，15 秒未开始播放会提示失败并允许重试。原曲入口随当前选曲更新并始终保留。
- 保留暂停续播、切歌重置及封面按需加载；离页时解除控件和媒体事件，释放音频、待执行请求和计时器。
- 新增 `templates/post.md`。新模板默认草稿；旧文章默认已发布。发布时必须有非空标题及有效日历日期，兼容旧版 `pubDate`，两个日期字段不一致时报错。
- 首页、文章总目、分类、详情、前后篇、RSS 及分享图统一调用 `getPublishedPosts()`；草稿不生成公开页面、草稿专属分类、分享图或站点地图条目。
